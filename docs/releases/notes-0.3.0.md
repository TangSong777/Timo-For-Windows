# Timo For Windows 0.3.0

这一版更小、更快，也补上了几种导出方式。

## 下载与使用

Release 里那个 `.exe` 就是安装包，**不需要装到系统里**，也不写注册表：

1. 下载 `TimoForWindows-0.3.0.exe`，随便放哪都行（双击运行）。
2. 选一个存放位置（默认是安装包旁边的 `Timo For Windows` 文件夹）。
3. 点「解压到这里」——解压完会自动打开程序，并**删掉这个安装包**，不占地方。
4. 以后启动用文件夹里的 `Timo For Windows.exe`；整个文件夹拷到别的电脑就能接着用，笔记在 `Data/` 里。

首次打开会让你导入 Timo 手机端的导出包（.zip），也可以选「从空白开始」。

## 新东西

- **搜索高亮**：搜出来的词在右侧预览里刷灰底，一眼看到在哪。
- **图库更顺手**：图片可以直接拖进去、`Ctrl+V` 贴图、`Delete` 删掉，支持多选。
- **导出 PDF**：笔记右键就能导成 PDF。
- **导出 Markdown 文件夹**：整库导出成一层主题目录 + 一堆 `.md`，图片走相对路径，拿去喂给别的编辑器也认。
- **大图查看器**：滚轮缩放，双击在「适应窗口 / 100%」之间切。
- **记得你上次看到哪**：重开程序回到原来的主题与笔记。

## 变更

- 回收站不再自动清理（上一版会静默删掉 30 天前的），现在只在你手动点「清空回收站」时才删。
- 应用锁去掉了，启动不再要密码。

## 体积与速度

- 解压后 127.6 MB（上一版 145.6），安装包 104 MB（上一版 112）。
- 主窗口打开 1.06 秒（上一版 1.46 秒）。

## 说明

- 程序没有签名，Windows 可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」即可。
- 笔记正文是 `Data/notes/*.md`，元数据在 `Data/library.json`，附件在 `Data/attachments/`，随时可以自己看、自己备份。
