Windows 本地笔记软件，可导入 Android Timo笔记 导出的数据包，离线使用，改完还能再导出回去。

## 下载

`TimoDesktop-0.1.0-win64.zip`，解压后双击 `Timo笔记.exe`。免安装，数据存在程序旁的 `data/` 目录。

## 主要内容

- **导入 Timo 数据**：支持官方「导出可读副本」的 ZIP 或解压后的文件夹，实测 32 主题 / 1005 笔记 / 83 附件约 5 秒导入
- **六种笔记类型**：便签、文章（Markdown 编辑 + 实时预览）、图库（图片墙 + 大图查看）、账号（账号/密码/备注卡片）、链接、日子（公历农历、每年重复）
- **整理能力**：搜索、置顶、8 种颜色标记、归档、回收站、跨主题移动；主题可拖拽排序，归档主题灰显
- **导出兼容**：生成与 Timo 官方结构一致的 ZIP，可再导回手机
- **自动保存**：停顿 0.7 秒写盘

## 验证

- `test_core.py` 13 项自动化测试全部通过
- 真实导出包导入后类型、状态计数与源数据完全一致
- 导出再导入：1005 条正文逐条比对 0 差异

## 说明

- 密码以明文保存在 `library.json`（与 Timo 的 `accounts.csv` 一致），程序不加密、不联网
- 手机端的指纹锁、提醒、云同步、小组件没有移植
- 非官方项目，与 Timo 官方无关

完整更新日志见 [CHANGELOG.md](https://github.com/TangSong777/Timo-Desktop/blob/master/CHANGELOG.md)。
